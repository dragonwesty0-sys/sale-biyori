# セール日和

Amazon と楽天市場のセール、ポイント還元イベントを日本時間で比較するカレンダーです。イベント条件は公式発表を確認して `events.mjs` に登録します。終了時刻は終了後最初の分（排他的）で保存します。「5と0のつく日」は公式の定例日から生成します。キャンペーン変更時は公式情報に合わせて一覧を更新してください。

## Cloudflare Pages

Git の本番ブランチを `main`、フレームワークをなし、出力ディレクトリを `dist` にします。ビルドコマンドには `sh build.sh` を指定します。公開 URL が確定したら正規 URL と XML サイトマップを設定します。

## 公式のお知らせの定期取得

1. Workers KV に名前空間を作成します。Pages プロジェクトの本番環境の KV バインディングに同じ名前空間を `NOTICES` として追加し、Pages を再デプロイします。
2. `wrangler.example.toml` を `wrangler.toml` にコピーして、名前空間 ID を設定します。Cloudflare に認証済みの環境から `npx wrangler deploy` で Worker をデプロイします。
3. Worker は3時間おきに公式一覧の関連リンクを取得します。初回実行後、Pages の `/api/notices` と画面の「公式の告知」を確認します。失敗した情報源の表示は前回結果を維持し、一部取得できなかったことを表示します。

取得したリンクは「公式の告知」に表示します。日時・還元条件の確定には公式発表の確認が必要なので、カレンダーの日付付きイベントには自動追加しません。
